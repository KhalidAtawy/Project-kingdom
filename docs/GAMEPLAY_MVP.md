# PROJECT KINGDOM — MVP Gameplay

## Core loop
Mission start → choose lanes → collect and multiply soldiers → reach battle → resolve combat → earn Gold and Kingdom Materials → upgrade the kingdom.

## First playable prototype
- Portrait mobile layout.
- Three lanes with swipe and keyboard fallback.
- Auto-forward movement.
- Add-soldier and army-multiplier gates.
- Visible army count and distance HUD.
- Restart after reaching the end of the prototype track.

## Planned next systems
1. Unit classes: Swordsman, Archer, Knight.
2. Enemy formations and automatic combat.
3. Boss encounter with telegraphed attacks.
4. Mission results and reward screen.
5. Kingdom hub and building upgrades.

## Current scope boundaries
Single-player first. No PvP, clans, live events, or monetization in the prototype. All characters, environments, UI, and names will be original.
