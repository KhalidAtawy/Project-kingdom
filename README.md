# PROJECT KINGDOM

An original mobile-first 3D army runner and kingdom progression game built with Godot 4.x.

## Current milestone
**M0 — Project foundation / M1 — First runner prototype**

The repository contains the initial Godot project structure, a portrait 3D runner scene, three-lane swipe movement, army growth gates, and a basic HUD.

## Open the project
1. Install Godot 4.x (standard GDScript build, not .NET).
2. Import this repository folder as a project.
3. Run the main scene.

## Controls
- Touch: swipe left or right to change lanes.
- Desktop test: A/D or left/right arrow keys.
- Tap/click after the run completes to restart.

## Current limitations
This is an early greybox prototype using primitive 3D shapes. It is not yet a polished game, has no enemy combat or kingdom progression, and has not yet been validated on Android or iPhone.

## Project files
- `project.godot` — project configuration.
- `scenes/Main.tscn` — main scene.
- `scripts/main.gd` — runner prototype logic.
- `docs/GAMEPLAY_MVP.md` — MVP gameplay outline.

## Original IP
Inspired by broad genre conventions only; no Top Lords assets, characters, maps, or UI are used.
